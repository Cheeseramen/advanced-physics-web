# 파동함수와 확률 해석 (Wave Function)

양자역학에서 입자의 상태는 **파동함수** $\psi(x,t)$로 기술된다.
고전역학에서 입자의 상태를 위치 $x(t)$와 운동량 $p(t)$로 정확히 기술하는 것과 달리,
파동함수는 복소수 값을 가지며 그 자체를 직접 관측할 수 없다.

관측 가능한 물리량은 파동함수의 **절댓값 제곱**이다.
보른(Born, 1926)은 이를 확률적으로 해석했다.

<LawBox title="파동함수와 확률밀도">

<DisplayMath formula="|\psi(x,\,t)|^2" />

는 시각 $t$에 위치 $x$에서 입자를 발견할 **확률밀도(probability density)**이다.

<DisplayMath formula="P(a \le x \le b) = \int_a^b |\psi(x,t)|^2\,dx" />

위치 $a$에서 $b$ 사이에서 입자를 발견할 확률은 위 적분으로 주어진다.

</LawBox>

입자는 반드시 공간 어딘가에 존재해야 하므로, 전체 공간에 걸쳐 발견될 전체 확률은 1이어야 한다.

<LawBox title="정규화 조건 (Normalization)">

<DisplayMath formula="\int_{-\infty}^{\infty}|\psi(x,t)|^2\,dx = 1" />

이 조건을 만족하는 파동함수를 **정규화된(normalized)** 파동함수라 한다.

</LawBox>

양자역학에서는 입자의 위치를 특정하지 않고, 단지 특정 위치에서 입자를 **발견할 확률**을 예측한다.
이는 측정 기술의 한계가 아니라 자연의 근본적인 성질이다.
