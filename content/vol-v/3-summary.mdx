<SummaryBox title="핵심 흐름">

- 로런츠 힘: $\mathbf{F}=q(\mathbf{E}+\mathbf{v}\times\mathbf{B})$ — 자기력은 일을 하지 않음
- 균일 자기장 속 원운동: $r=mv/(qB)$, $T=2\pi m/(qB)$
- 자기선속: $\Phi_B = \displaystyle\int\mathbf{B}\cdot d\mathbf{A}$
- 패러데이 법칙: $\varepsilon = -N\dfrac{d\Phi_B}{dt}$ (음의 부호 = 렌츠의 법칙)
- 운동 기전력: $\varepsilon = BLv$ ($\mathbf{v}\perp\mathbf{B}$, 길이 $L$인 도선)
- 자기 인덕턴스: $L = N\Phi_B/I$, 솔레노이드: $L = \mu_0 n^2 Al$
- 자기 에너지: $U_B = \dfrac{1}{2}LI^2$, $u_B = \dfrac{B^2}{2\mu_0}$
- 상호 인덕턴스: $\varepsilon_2 = -M\,dI_1/dt$, 변압기: $V_2/V_1 = N_2/N_1$

</SummaryBox>
