<SummaryBox title="핵심 흐름">

- 맥스웰 방정식은 갈릴레이 변환에 대해 불변이 아님 → 뉴턴 역학과 충돌 → **에테르 가설**
- 마이컬슨–몰리 실험 (1887): 에테르 바람 없음 → **에테르 가설 붕괴**
- 로런츠 (1904): 수학적 변환 발견; **아인슈타인 (1905)**: 두 공리로 시공간의 실제 구조 해명
- 두 공리: ① 상대성 원리 (모든 관성계에서 물리 법칙 동일) ② 광속 불변 원리
- 동시성의 상대성: 공간적으로 분리된 두 동시 사건은 다른 관성계에서 동시가 아님
- 시간 팽창: $\Delta t = \gamma\Delta t_0$ / 길이 수축: $L = L_0/\gamma$
- 상대론적 운동량: $p = \gamma m_0 v$ / 전체 에너지: $E = \gamma m_0 c^2$
- $E^2 = (pc)^2 + (m_0c^2)^2$ → 광자($m_0=0$): $E = pc$, $p = h/\lambda$ (양자역학으로 연결)

</SummaryBox>
